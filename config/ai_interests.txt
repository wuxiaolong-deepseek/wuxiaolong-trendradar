# 模式下,会用这个文件理解你的兴趣,然后给每条新闻打分。
#
# 写作原则:
#   - 用自然语言描述,不要写正则或关键词
#   - 明确说"想要"什么,以及"不要"什么
#   - 越具体,AI 匹配越准
#

# ───────────────────────────────────────────────────────────────
# 1. 我是谁(背景)
# ───────────────────────────────────────────────────────────────
我是 38 岁的东莞高中生物老师,11 年教龄。我个人对 AI 工具的实际应用感兴趣,
不是研究者,也不是开发者,不会写代码。

我关注 AI 主要是为了:
- 知道有哪些新工具/新功能,可以在日常工作和教学中尝试
- 了解主流 AI 产品的价格变化(我需要决定是否订阅)
- 跟踪 AI 教育和学习相关的新进展


# ───────────────────────────────────────────────────────────────
# 2. 我想要的内容(actionable + 工具/产品)
# ───────────────────────────────────────────────────────────────
我想要看到:

✓ **AI 工具/产品发布**:新的 AI 工具上线、Show HN、Product Hunt 上的新东西
✓ **价格变动**:DeepSeek 涨价、ChatGPT Plus 降价、Cursor 改订阅模式等
✓ **版本更新**:GPT-5 发布、Claude 4.5 上线、Cursor 0.X 重要功能
✓ **功能更新**:新模型支持多模态、新的 API 能力、企业版新功能
✓ **AI 教育相关**:Khanmigo 接入新课标、AI 助教新框架、智能批改工具
✓ **学习资源**:高质量 AI 教程、课程、Prompt 实战

这些"我能拿来用"或"会影响我决策"的信息。


# ───────────────────────────────────────────────────────────────
# 3. 我不想要的内容(噪音)
# ───────────────────────────────────────────────────────────────
我不想要看到:

✗ **行业八卦**:张一鸣内部讲话、某某 CEO 离职创业、马斯克起诉 OpenAI
✗ **科技新闻/政策**:中美贸易战、出口管制、IPO 估值(除非影响产品/价格)
✗ **娱乐/猎奇**:AI 替代谁工作、AI 是否觉醒、明星使用 AI 翻车
✗ **不实信息**:未经核实的传闻、夸张标题党、"震惊"类内容
✗ **我看不到的细节**:纯学术论文解读(我看不懂)、纯技术架构细节(我用不上)
✗ **重复信息**:同一事件被多个源报道,只保留 1 条(选信息量最大的)


# ───────────────────────────────────────────────────────────────
# 4. 输出偏好(给 AI 的指令)
# ───────────────────────────────────────────────────────────────
每条新闻 AI 应该:
1. **先判断是否符合我的兴趣**(从第 2、3 点)
2. **符合的给 actionable 标签**:
   - [新工具] - 新工具发布/Show HN
   - [价格变动] - 价格/订阅/计费变化
   - [版本更新] - 新模型/新版本
   - [功能更新] - 新功能/新能力
   - [学习资源] - 教程/课程/Prompt
   - [AI+教育] - AI 在教育场景
3. **不符合的直接 drop**(不显示在推送里)
4. **重复的合并**:"[重复:机器之心也报道了] 同一事件"
5. **每条不超过 50 字中文摘要**
6. **不确定时偏向 drop**(宁可不推,不要错推)


# ───────────────────────────────────────────────────────────────
# 5. 语言偏好
# ───────────────────────────────────────────────────────────────
- 中文为主
- 英文标题可以保留原文,但摘要要翻译成中文
- 不需要解释专业术语(我看得懂)


# ───────────────────────────────────────────────────────────────
# 6. 数量偏好
# ───────────────────────────────────────────────────────────────
- 每天推送控制在 **8-15 条**(再多就看不过来了)
- 优先 actionable 标签
- 同类内容(都是 [新工具])不要超过 3 条
